# Reporting a security concern

Report suspected vulnerabilities privately. If this repository offers
**Security → Report a vulnerability**, use that private reporting option.
Otherwise, use the [official Selectec contact page](https://selectec.com/contact/)
to ask for a private security reporting channel. Start with a high-level
description and a way to contact you; send sensitive details only after the
appropriate private channel has been established.

Do not open a public issue or pull request containing vulnerability details,
credentials, callback codes, signed URLs, tenant addresses, customer data or
production logs. If credentials have been exposed, handle their replacement
through the credential owner's normal process rather than posting them here.

A useful private report includes the affected package version, the behavior and
its impact, and reproduction steps using synthetic data where possible. Please
check whether the issue also occurs with the latest release or current default
branch, if you can do so safely. Do not access or modify another person's data
to demonstrate a problem.

Ordinary bugs with no security implications can use the repository's bug-report
form, following the [contribution guidance](CONTRIBUTING.md).
